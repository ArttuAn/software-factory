# Software Factory identity

The mark combines a factory roof and an inspection check. A small spark represents agent work; the check represents evidence required before handoff. The logo is original SVG artwork created for this project.

| Asset | Purpose |
|---|---|
| `web/assets/logo.svg` | Horizontal wordmark on light backgrounds |
| `web/assets/logo-mark.svg` | App icon, favicon and compact identity |
| `web/assets/hero.svg` | Repository cover and workflow graphic |
| `web/assets/icons.svg` | Consistent 24px interface icon sprite |

Palette: forest `#173E34`, lime `#D5EF83`, warm white `#F5F6EF`, graphite `#24372E`. Amber means attention or validation, red means blocked, green means a successful observed state. Text accompanies every status; color is never the only signal. The native engine's state and the factory handoff verdict remain distinct.

Icons use a 24 × 24 grid, 1.7px rounded strokes and semantic text labels. Decorative SVGs are hidden from assistive technology. No external fonts, image services or asset CDN are required.

GitHub topics describe the repository. Issue labels describe work: `type: bug`, `type: feature`, `type: docs`, `type: maintenance`; `area: agents`, `area: quality-gate`, `area: ui`, `area: github`; `priority: high`, `priority: normal`; `status: blocked`, `status: ready`, plus `good first issue` and `help wanted`. The first branded source version is tagged `v0.1.0`.
